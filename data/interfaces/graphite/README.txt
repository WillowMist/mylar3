Graphite Interface
===================

A mobile-optimized dark theme for Mylar3.

Features:
- Bootstrap 5 for responsive layout
- Mobile-first design with collapsible navbar
- Touch-friendly button sizes (min 44px)
- Responsive tables
- Dark color scheme (blue-gray)
- Inherits from default templates (fallback mechanism)

Color Scheme:
- Background: #2c3e50 (blue-gray)
- Header: #1a252f (darker)
- Text: #ecf0f1 (light gray)
- Accent: #3498db (bright blue)

Usage:
- Select "graphite" as the interface in Mylar config
- Templates not found in graphite/ fall back to default/
- Icons symlinked to carbon/ (can be changed if needed)
